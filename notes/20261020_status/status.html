How to try it

  • Open http://127.0.0.1:8765 while the service runs. It serves ~/na-vault-copy, a copy of the real vault, so nothing you apply touches the real one.
  • Start it yourself: uv run notebook-assistant serve --vault ~/na-vault-copy in the repo (Ctrl+C stops it within 2 s).
  • Calls to the Claude API cost credit: Chat, Inbox → Process, Approve to digest, Sweep changes. Everything else is free.
  • This PC's config.yaml has search: e5-small (meaning search on); Settings switches it back.
